# Íconos NIXIS (públicos)

Íconos de las apps NIXIS que necesitan una URL pública (por ejemplo, el favicon de una app de Google Apps Script,
que solo acepta un enlace). Generados desde los logos del estándar de diseño con `crear_ico.dibujar` (nunca a mano).

| Archivo | Uso |
|---|---|
| `mutuo-32.png` | Favicon de NIXIS Mutuo |
| `mutuo-180.png` | Ícono para pantalla de inicio (180 px) |
| `mutuo-512.png` | Ícono grande |
| `mutuo.svg` | Vector original (diamante índigo) |

Solo contiene logos de la marca: nada privado.
